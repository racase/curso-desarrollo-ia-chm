# AGENTS.md (raíz)

Este repositorio contiene dos proyectos independientes. No hay código en la raíz.

- `web/`: aplicación Laravel + Filament. Lee `web/AGENTS.md`.
- `datos/`: proyecto Python sobre PostgreSQL/TimescaleDB. Lee `datos/AGENTS.md`.

Reglas comunes:

- Trabaja solo dentro de la carpeta del proyecto que te indiquen; no mezcles cambios de ambos.
- Código, nombres de ficheros y commits en inglés. Documentación y textos de interfaz en español.
- No leas ni modifiques ficheros `.env`. Usa `.env.example` como referencia.
- Commits pequeños con formato Conventional Commits.
